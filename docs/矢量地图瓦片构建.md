# 矢量地图瓦片（PMTiles）构建说明

玩无一失的行程地图默认走 **高德位图兜底**（国内可达）。要升级成 TripProf 同款
**矢量质感**（平滑无级缩放 / 建筑轮廓 / 精致底图），只需往 `public/` 放一个
`tiles.pmtiles` 文件 —— `MapPanel` 会自动 HEAD 探测并切换到矢量底图，无需改代码。

瓦片随 GitHub Pages 一起部署，**零成本、无 key、大陆可达**。

## 一键构建（法意瑞范围）

```bash
./scripts/build-pmtiles.sh            # 正常构建
./scripts/build-pmtiles.sh --force    # 忽略缓存重新拉取
MAXZOOM=13 ./scripts/build-pmtiles.sh # 更高细节（注意 100MB 上限）
```

### 本机依赖（**无需 Homebrew / Xcode CLT**）
脚本会自动下载所需二进制，无需任何包管理器：
- **Java 21**：若系统没有或版本 <21，脚本从 **Adoptium 官方**下载 Temurin 21 tar 包解压到 `.tilebuild/jdk`（不解系统全局）。
- **pmtiles**：从 **GitHub Releases** 下载官方单文件二进制（零依赖）到 `.tilebuild/`。
- **Planetiler jar**：从 GitHub Releases 下载最新版到 `.tilebuild/`。
- 仅需要系统自带的 `curl`。

> 若公司网络拦了 GitHub/Adoptium，可手动把上述三个文件下好放进 `.tilebuild/`
> （jdk 解压后含 `bin/java`、二进制命名 `pmtiles`、jar 命名 `planetiler.jar`），再跑脚本即可跳过下载。

### 流程
1. 每个国家：`Planetiler --area=france|italy|switzerland` **自动下载 Geofabrik 数据**并输出该国 `*.pmtiles`（OpenMapTiles schema）
2. `pmtiles merge` 把三国合成一个 `public/tiles.pmtiles`
3. 刷新浏览器 → 行程 → 地图，即见矢量底图

（早期版本用 `osmium` 裁剪合并，已弃用——为避开 brew/CLT 依赖，改为「按国家分别构建 + pmtiles merge」。）

## 为什么是这些选型
- **Planetiler 默认输出 OpenMapTiles schema**，正好匹配 `MapPanel` 的 `vectorStyle`
  （`water` / `landcover` / `building` / `transportation` 四层都会渲染）。
- 矢量样式**不含文字层**，因此**不需要外部字体 glyphs CDN**，完全自包含、离线可用；
  城市名由 `MapPanel` 的 HTML Marker 叠加，POI 名在点开弹卡时显示。
- **海外（欧洲）瓦片直出 WGS-84**，与本项目世界库坐标一致，无需 GCJ-02 偏移换算。

## 部署注意
GitHub 对**单文件 100MB** 有硬上限，无法 `git` 提交更大的文件：
- z12 法意瑞约 20–60MB，可直接提交部署；
- 若需要 z13+ 更高细节导致 >100MB，要么降低 zoom，要么把 `tiles.pmtiles`
  挂到外部免费静态托管，再改 `MapPanel` 里的 `pmUrl`（见 `src/features/trip/MapPanel.tsx`）。

## 兜底
没有 `tiles.pmtiles` 时，地图自动回退到高德位图，不会白屏。

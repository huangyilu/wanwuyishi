### 世界库
- 定义：项目的静态知识数据源，存放国家、城市、POI（景点）等权威参考信息，以 `content/**/*.json` 形式用 Git 管理，构建后生成 `public/data/**.json` 索引供前端加载。与运行时行程数据严格区分。
- 别名：world library、world data、世界库数据

### 行程
- 定义：用户创建的旅行计划（trips），包含日程、条目、票券、账本、成员等运行时数据，持久化在 Supabase Postgres，通过 Repository 抽象由前端读写。
- 别名：trip、行程数据

### POI
- 定义：Point of Interest（兴趣点/景点），世界库中的最小知识单元，如博物馆、地标、公园等，每个 POI 有结构化字段（开放时间、预约要求、导览路线等）和配图。
- 别名：景点、兴趣点、poi

### 幽灵成员
- 定义：尚未注册账号、仅以 display_name 存在于 trip_members 表中的行程参与者。可被投票、记账、结算；后续认领后可继承全部历史，无需数据迁移。
- 别名：ghost member、幽灵成员

### 分享快照
- 定义：发布行程时经隐私净化生成的只读 JSON 快照，存入 `shares.payload`，通过 RPC `get_share(slug)` 按 slug 精确获取，用于生成匿名可访问的分享链接 `/s/:slug`。
- 别名：share snapshot、分享页、快照

### 无脑跟随
- 定义：从他人分享的行程快照导入为新行程的功能：提取原行程的天与条目结构，根据新出发日期重映射时间，自动校验闭馆日冲突并给出换日建议，最终批量创建新行程。
- 别名：follow trip、clone from share

### 送签国
- 定义：根据行程在各国的过夜数判断应向哪个国家的使领馆递交签证申请的国家；申根区内同区国家共享一张签证卡。
- 别名：visa country、递签国

### AA 账本
- 定义：多人旅行费用分摊与结算模块：按权重将金额精确分配到各成员（整数分，无浮点误差），计算净额后用回溯算法求最少转账次数完成结清。
- 别名：expense split、AA 分摊、结算

### 闭馆日校验
- 定义：行程编排时的核心算法之一：根据 POI 的 `closedWeekdays`、`closedDates`、`seasonal` 字段检测条目是否安排在闭馆日，并给出同城其他日期的换日建议。
- 别名：closure check、闭馆检查

### 世界库 POI 补充 Skill
- 定义：项目本地 Skill（`world-poi-add`），用于向 world 库添加新的 POI 或城市数据：确认城市存在 → 编写符合 PoiSchema 的 JSON → 配图（Wikimedia Commons 自由版权图）→ 运行 `content:validate` + `content:build` 校验。与「行程编辑」走不同通道。
- 别名：world-poi-add、POI 补充 skill、世界库 skill

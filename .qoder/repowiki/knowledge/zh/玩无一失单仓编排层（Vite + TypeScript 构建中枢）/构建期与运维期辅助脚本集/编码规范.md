- 脚本入口统一以 `main()` 函数定义并在文件末尾立即调用，错误通过 `process.exit(非0)` 上报。
- 内容类脚本通过 `content-io.ts` 暴露的 `loadContent()` 统一加载与解析 `content/` 下的 JSON，避免重复实现文件遍历与 schema 校验。
- 对外部网络请求（Wikimedia API、GitHub Releases）统一使用 `curl` 子进程而非 Node fetch，以规避沙箱环境限制。
- 图片采集脚本维护 `credits.json` 记录每张图片的作者、许可与来源页面，用于 UI 署名展示。
- 校验脚本将问题分级为 error/warn，error 累计导致非零退出码，warn 仅打印提示，便于 CI 门禁集成。

本模块为纯数据层，按地理粒度划分为三个并列子目录：`content/countries/<iso2>.json` 存放国家元信息（签证、货币、紧急电话等），`content/cities/<slug>.json` 存放城市生存指南与通票，`content/pois/<slug>.json` 存放景点基础信息与可选的 `guide` 深导览；每个实体通过 `id` 字段建立跨引用（如 POI 的 `city` 指向 `city-<slug>`，`country` 指向 ISO 代码）。图片资源独立放在 `public/img/{cities,pois}/` 下，文件名遵循 `city-<slug>.jpg` / `poi-<slug>.jpg` 命名约定，并配套同级 `credits.json` 记录图片来源。该目录仅为人类/AI 编辑的**源数据**，不直接参与运行；由 `npm run content:build` 产出到 `public/data/`，并由 `npm run content:validate` 在 CI 中校验结构完整性与业务规则（如 `volatile` 字段必须带 `source` 与 `verifiedAt`、闭馆日必须结构化、高热度博物馆必须配 `guide`）。

模块按职责划分为四个清晰层次：
- UI 组件层：`WorldNav.tsx` 实现国家/城市/景点三级可折叠树、关键词搜索、快速排除标签与 `@dnd-kit/core` 拖拽；`PoiGuideCard.tsx` 导出 `PoiGuideCardView`（纯展示）与 `PoiGuideCard`（带 `usePoi` 拉取），渲染门票/开放/路线/亮点/设施等区块并集成 `Lightbox` 与 `TicketEditor`。
- 数据访问层：`queries.ts` 通过 `@tanstack/react-query` 封装 `useWorldIndex/usePois/usePoi/useCity/useCountry/usePoiMap`，统一使用 `staleTime: Infinity, gcTime: Infinity` 表明世界库为构建期静态内容，运行时永不过期。
- 资源映射层：`cityImages.ts` 与 `poiImages.ts` 以 `Record<string, {src, author, license, page}>` 形式维护来自 Wikimedia Commons 的自由版权配图，并提供同名查找函数，将 id→图片元数据的映射与业务逻辑解耦。
- 依赖方向：组件 → queries → `../../data` 暴露的 `useWorld()` 客户端；样式全部走 CSS Modules（`.module.css`）；业务类型来自 `../../data/types` 与 `../../domain/world/schema`，状态由 `../../store/workbench` 提供筛选上下文。

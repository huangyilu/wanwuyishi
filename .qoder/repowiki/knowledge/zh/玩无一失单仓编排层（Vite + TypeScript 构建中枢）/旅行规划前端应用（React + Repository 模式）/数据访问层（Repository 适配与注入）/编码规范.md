- 每个 adapter 类都声明 `kind` 字面量类型（'local' | 'supabase'）与 `capabilities.canWrite/canSync`，由 UI 据此决定是否显示编辑入口与同步状态。
- Supabase adapter 使用独立的 `mapXxx(r)` 函数将数据库 snake_case 行对象转换为驼峰领域类型，字段名与 `0001_init.sql` 迁移严格一一对应。
- 写操作统一通过 `updatedAt = now()` 更新时间戳，并在 mutate 包装器中落盘，保证变更可追踪。
- 可选字段在读取时做降级填充（如 `kind ?? 'poi'`、`splitMode ?? 'aa'`、`images ?? []`、`ownerId ?? null`），避免调用方到处判空。
- 仓库方法对错误直接 throw（网络错误、RLS FORBIDDEN、外键冲突 23503 等），由上层统一捕获并提示，adapter 内部不吞异常。
- 世界库查询通过 `memo` 高阶函数对 `getJson` 结果做 Promise 级内存缓存，并按需加载 country/city/poi/aliases/search 多个 JSON 文件。

模块按职责拆分为两个并列目录：`src/ui/` 存放全局可复用的视觉原语（`illustrations.tsx` 提供空状态 SVG 插画、`toast.tsx` 通过 React Context + `useContext` 暴露 `ToastProvider`/`useToast` 实现全局通知），以及共享样式入口 `base.css`、`tokens.css` 和设计 token；`src/components/` 存放具体交互组件（`ClickableImage` 使用 `createPortal` 将灯箱渲染到 `document.body`，`CopyButton` 封装剪贴板写入）。所有组件均为无外部框架依赖的纯 React 函数组件，样式统一采用 CSS Modules（`.module.css`）并通过 CSS 变量（如 `--brand`、`--line-strong`、`--gold`）与设计 token 联动，组件之间无相互引用，仅向上依赖 CSS 变量与浏览器原生 API。

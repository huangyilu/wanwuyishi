- 组件以单文件形式组织，同名 `.tsx` 搭配同名的 `.module.css` 进行样式隔离。
- 颜色与尺寸等视觉值统一通过 CSS 变量（`var(--brand)`、`var(--line-strong)`、`var(--gold)` 等）注入，组件内部不硬编码色值。
- 对外暴露的组件均定义明确的 Props TypeScript 类型，并以具名函数导出。
- 全局状态型组件（如 Toast）通过 React Context + `useContext` 钩子暴露消费接口，而非 props 透传。
- 需要脱离文档流渲染的弹窗类组件（Lightbox）统一使用 `react-dom/createPortal` 挂载至 `document.body`。

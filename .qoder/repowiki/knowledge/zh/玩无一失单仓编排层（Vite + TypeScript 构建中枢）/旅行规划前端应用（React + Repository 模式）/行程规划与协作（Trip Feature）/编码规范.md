- 所有写操作统一通过 `useTripMutations(tripId)` 暴露的 mutation 调用，并在 `onMutate` 中就地修改 `TripBundle` 缓存实现乐观更新，`onError` 用 `rollback(ctx)` 回滚，`onSettled` 失效相关 queryKey。
- 组件通过 `useTripRepo().kind === 'supabase'` 或 `isCloudStorage()` 判断是否启用云端能力（协作、附件上传），本地模式降级为纯 localStorage。
- 成员身份判定统一走 `useMyMember(members)` / `pickMyMember`，优先按 `user.id` 匹配 `trip_members.user_id`，未登录时降级到 `role === 'owner'`。
- 拖拽数据通过 `data.current` 携带 `{ kind, itemId, dayId }` 等元信息，在 `onDragEnd` 中统一解析并计算 fractional rank（`rankForInsert` / `rankBetween`）后写入。
- 重型子模块（如 `MapPanel`）使用 React `lazy(() => import(...))` 按需加载，减少首屏体积。
- 样式一律使用 CSS Modules（`import s from './X.module.css'`），并按组件粒度拆分 `.module.css` 文件，地图标记样式抽到共享 `mapMarkers.css`。

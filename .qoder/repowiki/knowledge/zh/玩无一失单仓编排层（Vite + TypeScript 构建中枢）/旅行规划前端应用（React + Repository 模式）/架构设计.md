应用采用四层分层架构：app_shell 提供入口 main.tsx，自上而下注入 QueryClientProvider → RepositoryProvider（在 data/index.tsx 中根据 isSupabaseConfigured 选择 SupabaseTripRepository 或 LocalTripRepository）→ ToastProvider → RouterProvider；所有页面与特性组件均在此树内消费。data_layer 通过 TripRepository / WorldRepository 接口屏蔽 Supabase、localStorage 与静态 JSON 三种数据源，使 features/auth、features/trip、features/world 仅依赖抽象而不感知后端切换。domain_models 提供纯函数式业务规则（行程排程、费用结算、签证目的地、景点时长等），被多个特性共享作为 UI 与数据层之间的契约。ui_primitives 与 shared_helpers 提供跨特性复用的原子组件、CSS token、Zustand 工作台状态与下载工具。路由由 app/router.tsx 基于 react-router-dom HashRouter 组织 TripsPage / TripPage / WorldPage 三大页面，AuthBar/LoginDialog 等认证能力以 Feature 形式挂载到页面之上。

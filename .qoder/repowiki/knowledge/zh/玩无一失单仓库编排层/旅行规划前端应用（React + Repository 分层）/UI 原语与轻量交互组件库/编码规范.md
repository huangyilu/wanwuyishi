- 每个组件采用单文件组织，同名 `.tsx` 搭配同名的 `.module.css` 进行样式隔离。
- 颜色与尺寸等视觉值统一通过 CSS 变量（如 `var(--brand)`、`var(--line-strong)`、`var(--gold)`）注入，组件内部不硬编码色值。
- 对外暴露的组件均定义明确的 Props TypeScript 类型，并以具名函数形式导出。
- 需要脱离文档流渲染的弹窗类组件（Lightbox、PdfViewer）统一使用 `react-dom/createPortal` 挂载至 `document.body`，并在 `useEffect` 中绑定 ESC 键关闭与 `document.body.style.overflow = 'hidden'`。
- 全局状态型能力（Toast）通过 React Context + `useContext` 钩子暴露消费接口，而非 props 透传。
- 对外部资源加载（PDF）采用 try/catch 静默失败策略，避免阻断用户主交互流程。

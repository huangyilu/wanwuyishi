模块采用 Repository 模式：`types.ts` 集中定义 `TripRepository`、`WorldRepository` 两个纯接口以及全部领域类型（Trip/TripItem/Expense/Ticket/Poi/Country 等），是上层唯一依赖的契约；`adapters/` 下实现三种后端——`SupabaseTripRepository`（调用 Supabase RPC `get_trip_bundle`、受 RLS 保护）、`LocalTripRepository`（基于 localStorage `wwys:trips:v1` 键，`canSync=false` 仅开发演示用）、`StaticJsonWorldRepository`（从 `/data/*.json` 加载世界库并内存缓存）。`index.tsx` 提供工厂 `createRepositories()`，依据 `supabase-client.ts` 中的 `isSupabaseConfigured`（由 `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` 决定）选择 trip adapter，world 始终走静态 JSON；并通过 `RepoContext` + `RepositoryProvider` + `useRepositories`/`useTripRepo`/`useWorld` 暴露为 React 上下文。`supabase-client.ts` 集中管理 Supabase 客户端单例、会话监听 `useSession` 以及匿名/邮箱 OTP/密码登录登出 API，所有写操作受 RLS 约束，未登录时自动回退到本地 adapter。依赖方向单向：`adapters/*` → `types` + `domain/world/schema` + `domain/trip/rank`，`index.tsx` 聚合 adapters 并注入 React Context，视图层只感知接口。

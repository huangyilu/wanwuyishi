模块以 React 组件 + react-query hooks 的形式组织，围绕 `useSession`（来自 `../../data/supabase-client`）这一单一认证源展开：
- UI 层：`AuthBar.tsx` 作为双端共用的顶栏入口，根据 `isSupabaseConfigured` 决定是否渲染；未登录时弹出 `LoginDialog`，已登录时显示用户名药丸并弹出 `AccountDialog`。
- 交互层：`LoginDialog` 封装邮箱+密码登录/注册、匿名快速体验、邮箱 OTP 魔法链接四种方式，统一通过 `run` 辅助函数处理 loading/error/ok 状态；`AccountDialog` 负责修改 `profiles.display_name` 并登出。
- 数据层：`useProfile.ts` 暴露 `useProfile`（读取当前用户 profile）和 `useUpdateDisplayName`（upsert 到 profiles 表），并通过 `react-query` 的 `invalidateQueries` 在名称变更后刷新 `['profile']`、`['trip','bundle']` 等分组。
- 同步层：`AuthQuerySync.tsx` 订阅 session 变化，在登录/登出后调用 `qc.invalidateQueries({ queryKey: ['trip'] })`，解决 RLS 切换导致的陈旧缓存问题。
依赖方向单向向下：UI → hooks → `supabase-client`，不反向依赖业务仓库，仅通过 react-query 键名约定与上层共享缓存。

- 所有需要鉴权的请求都先通过 `useSession()` 获取 user，再结合 `enabled: !!userId` 或 `!!supabase` 条件启用查询，避免无会话时发起无效请求。
- 弹窗组件统一接收 `onClose` prop，并以 overlay + card 结构包裹，点击遮罩或 ESC 键关闭，同时设置 `role="dialog"`、`aria-modal`、`aria-labelledby` 等无障碍属性。
- 表单操作统一通过内部 `run(fn, okMsg?)` 辅助函数包装，集中处理 busy/loading、错误消息与成功提示，保持 LoginDialog 中各登录分支逻辑一致。
- 对 supabase 表的写操作使用 `upsert(..., { onConflict: 'id' })` 确保 profile 行不存在时可自动创建，并在 `onSuccess` 中通过 `invalidateQueries` 按 key 分组失效相关缓存。
- 组件内样式一律通过 CSS Modules 引入（`import s from './xxx.module.css'`），HTML 类名复用全局 `btn`、`field` 等基础类，模块类仅用于弹窗布局。

- 所有表主键使用 `uuid primary key default gen_random_uuid()`，外键统一带 `on delete cascade` 或 `set null` 以处理成员注销等场景。
- 金额字段一律使用 `bigint` 表示“分”（amount_cents、price_cents），避免浮点精度问题。
- 敏感字段（booking_ref、personal_notes.content）通过 RLS 策略隔离，不在分享快照 payload 中输出。
- RLS 权限判定统一委托给 `public.is_trip_member` / `is_trip_owner` 两个 SECURITY DEFINER 函数，策略中只引用这些函数而不直接 join trip_members。
- 迁移与附件脚本均使用 `if not exists`、`drop if exists`、`create or replace function` 等语句，支持重复执行。
- RPC 函数使用 `security definer` 并在函数内部显式校验 `auth.uid()` 与成员资格，再通过 `grant execute ... to authenticated/anon` 控制访问范围。

- 数据访问统一通过 Repository 接口（TripRepository / WorldRepository）暴露，视图层使用 useTripRepo / useWorld 获取实例，禁止直接调用适配器。
- 所有异步数据读取与缓存统一走 @tanstack/react-query，并在 main.tsx 中关闭 refetchOnWindowFocus 以避免标签切换闪烁。
- 领域逻辑集中在 domain/ 下的纯函数模块，不依赖 React、DOM 或任何 UI 框架，供多个特性复用。
- 样式采用 CSS Modules（*.module.css）配合 ui/tokens.css 中的 CSS 变量，避免全局样式污染。
- 特性按 features/<name>/ 目录组织，每个特性内部自包含组件、查询与样式，仅通过 data 层与 domain 层与其他特性解耦。

- 所有金额统一以整数分（cents）参与运算，禁止使用浮点小数，分摊差额通过最大余数法补齐以保证总和守恒。
- 所有日期以 `YYYY-MM-DD` 字符串形式在领域内流转，仅在 `date.ts` 中通过 UTC 毫秒换算进行加减与差值计算。
- 可变信息（价格、开放时间、预约要求等）采用 `Verifiable<T>` 包装，强制携带 `value`、`source`、`verifiedAt` 三要素。
- 每个领域函数都配套同名的 `.test.ts` 单测文件，覆盖边界条件与典型用例。
- 开放状态用结构化字段（`closedWeekdays`、`closedDates`、`seasonal`）表达，算法直接读取而非解析自然语言。
- 导出接口优先使用具名函数 + TypeScript interface 描述输入输出，保持纯函数风格，不维护内部状态。

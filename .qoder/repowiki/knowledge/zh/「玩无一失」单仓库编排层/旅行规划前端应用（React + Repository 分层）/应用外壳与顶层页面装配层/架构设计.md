模块由 `src/app`（应用装配与外壳）和 `src/pages`（顶层页面）两部分构成，是前端应用的根边界。
- 启动装配：`main.tsx` 通过 `createRoot` 挂载根节点，自上而下包裹 `QueryClientProvider`（关闭 window focus refetch）、`RepositoryProvider`、`ToastProvider`、`AuthQuerySync`，最后渲染 `RouterProvider` 与开发工具 `DevAgentation`。
- 路由定义：`router.tsx` 使用 `createHashRouter`（适配 GitHub Pages 静态部署），以 `/` 为根嵌套 `AppShell`，子路由映射到 `TripsPage`、`TripPage`、`WorldPage`，并处理 `world/poi/:poiId` 与 `*` 404。
- 外壳分流：`AppShell.tsx` 通过 `useViewMode` 在 `DesktopShell`（顶部导航 + 品牌 + `Outlet`）与 `MobileShell`（底部标签栏 + 右上角头像菜单）之间切换，两者共享 `AuthBar`、`JoinDialog`（深链 `?token=xxx` 自动弹出加入弹窗）。
- 页面组织：`TripsPage` 负责行程列表与新建；`TripPage` 作为双端分流点，按模式 lazy 加载 `Workbench`（桌面）或 `MobileTrip`（移动），并通过 tab 切换懒加载 `LedgerPanel`、`PackingPanel`，同时提供 Markdown 导出/预览与协作邀请；`WorldPage` 独立浏览世界库，按国家/城市分组展示 POI，移动端走单列详情流。
- 依赖方向：本模块仅向上依赖 `../data`、`../features/*`、`../hooks`、`../ui`、`../domain`、`../utils`，不暴露任何内部 API，所有对外能力通过路由与组件 props 暴露。

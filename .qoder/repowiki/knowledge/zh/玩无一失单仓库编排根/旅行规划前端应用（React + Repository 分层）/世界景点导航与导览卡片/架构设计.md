模块按职责划分为四层：UI 组件层由 `WorldNav.tsx`（国家/城市/景点可折叠树、关键词搜索、快速排除标签、`@dnd-kit/core` 拖拽）和 `PoiGuideCard.tsx`（导出纯展示 `PoiGuideCardView` 与带 `usePoi` 拉取的 `PoiGuideCard`，渲染门票/开放/路线/亮点/设施等区块并集成 `Lightbox`、`TicketEditor`）组成；数据访问层集中在 `queries.ts`，通过 `useWorldIndex/usePois/usePoi/useCity/useCountry/usePoiMap` 六个自定义 hook 封装 `@tanstack/react-query` 查询，统一使用 `{ staleTime: Infinity, gcTime: Infinity }` 标记世界库为构建期静态内容；资源映射层由 `cityImages.ts` 与 `poiImages.ts` 以 `Record<string, {src, author, license, page}>` 集中声明 Wikimedia Commons 自由版权配图，并提供同名查找函数解耦 id→图片元数据；依赖方向为 组件 → queries → `../../data` 暴露的 `useWorld()` 客户端，样式全部走 CSS Modules，业务类型来自 `../../data/types` 与 `../../domain/world/schema`，状态由 `../../store/workbench` 提供筛选上下文。

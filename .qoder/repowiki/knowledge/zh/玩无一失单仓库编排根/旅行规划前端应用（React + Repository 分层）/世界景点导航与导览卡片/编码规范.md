- 所有世界库数据查询统一通过 `queries.ts` 中的自定义 hook 暴露，并使用 `{ staleTime: Infinity, gcTime: Infinity }` 标记为构建期静态内容。
- 组件样式一律采用 CSS Modules（`import s from './xxx.module.css'`），并通过模板字符串组合多个 class 名表达状态（如 `chipOn`、`cityOn`、`poiDragging`）。
- 图片资源以 `Record<string, ImageMeta>` 常量集中声明，再暴露同名 `xxxImage(id)` 查找函数，将 id→图片元数据的映射与业务逻辑解耦。
- 对可选数据（如 `index`、`pois`、`id`）普遍使用 `?? []` / `?? 0` / `enabled: Boolean(id)` 进行防御式渲染与条件启用。
- 可折叠分组（国家/城市）使用 `Set<string>` 存储展开态，并通过独立的纯函数（如 `toggleCountry`）生成新集合后调用 setState，保持不可变更新。
- 易过期字段（票价/开放时间/预约）通过 `freshnessOf` 与 `oldestVerification` 计算新鲜度，并以 `VolatileRow` 子组件统一渲染来源链接与警告横幅。

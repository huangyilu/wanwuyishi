- 通过 `useViewMode()` 在组件内判断当前模式，分别渲染桌面与移动两套 UI，实现“非响应式的双端分流”。
- 重型功能组件（如 Workbench、MobileTrip、LedgerPanel、PackingPanel）统一使用 `React.lazy(() => import(...))` 配合 `<Suspense>` 进行代码分割。
- 每个页面与外壳组件配套一个同名 `.module.css` 文件，通过 `import s from './xxx.module.css'` 引入并使用 `s.xxx` 类名。
- 页面组件通过 `react-router-dom` 的 `useParams` / `useNavigate` / `useLocation` / `useSearchParams` 读取路由参数并触发导航，而非直接操作 URL。
- 需要跨端共享的全局上下文（查询客户端、仓库、Toast、认证同步）在 `main.tsx` 中自顶向下用 Provider 包裹，页面组件通过 hooks 消费。

模块按职责划分为两个并列目录：`src/ui/` 存放全局视觉原语——`illustrations.tsx` 通过 `EmptyArt` 分发三种内联 SVG（route/map/compass）作为空状态占位；`toast.tsx` 用 React Context + `useContext` 暴露 `ToastProvider`/`useToast`，在应用根节点包裹后任意子组件均可调用 `toast(msg, kind)` 弹出 3.2s 自动消失的提示；同时导出 `base.css` 与 `tokens.css` 作为全局样式入口。`src/components/` 存放具体交互组件：`ClickableImage` 组合内部受控的 `Lightbox`，后者通过 `react-dom/createPortal` 挂载到 `document.body` 并监听键盘 ESC/方向键实现画廊切换；`CopyButton` 封装 `navigator.clipboard.writeText` 并提供 `asSpan` 模式以适配嵌套场景；`PdfViewer` 通过 Supabase Storage 客户端下载文件为 Blob 后用 `URL.createObjectURL` 创建本地 PDF URL 再经 `<iframe>` 渲染，同样使用 `createPortal` 弹出。所有组件之间无相互引用，仅向上依赖 CSS 变量（`--brand`、`--line-strong`、`--gold` 等）与浏览器原生 API，形成单向、无环的依赖结构。

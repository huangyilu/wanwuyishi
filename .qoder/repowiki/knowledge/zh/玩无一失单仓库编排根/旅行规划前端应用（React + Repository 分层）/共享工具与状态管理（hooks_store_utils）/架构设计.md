本模块由三个并列的横向切片组成，彼此无依赖：
- `src/hooks/useViewMode.ts`：通过模块级单例 state + `useSyncExternalStore` 订阅媒体查询变化，实现桌面/移动端双布局切换，并以 `localStorage` 中的 `wwys:viewMode` 键支持手动覆盖，保证 AppShell 与各 Shell 子树共享单一真相源。
- `src/store/workbench.ts`：使用 Zustand 的 `create` 定义工作台状态（选中日期、Inspector 多态面板、城市筛选、关键词、排除标签、调试开关），并通过 `sessionStorage`（`wwys:workbench`）在刷新后恢复关键筛选上下文；持久化策略为写操作后调用 `persist(get())` 增量保存。
- `src/utils/download.ts`：纯函数集合，基于原生 `Blob` + `<a download>` 实现文本文件下载，并提供文件名安全化工具，不依赖任何框架或第三方库。
依赖方向单向向外：hooks 仅依赖 React 与 Web API，store 仅依赖 Zustand，utils 零依赖。
